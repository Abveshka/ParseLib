# ParseLib

**ParseLib** - проект, реализующий три парсера для сбора и структурирования данных из разных веб-источников.

### Парсер Habr

Собирает публикации с сайта Habr из заданного диапазона страниц.

### Агрегатор театральных афиш

Собирает информацию о спектаклях из афиш трёх театров города Кирова:

- Театр на Спасской
- Кировский областной драматический театр имени С. М. Кирова
- Кировский театр кукол

Парсер получает данные о спектаклях за **все месяцы, доступные на сайтах**.

### Парсер BookMix

Собирает пользовательские отзывы на книги и используется для исследования производительности многопоточной загрузки.

Для ускорения сбора данных многопоточность применяется на двух этапах:

1. **Параллельная загрузка страниц** со списками отзывов.
2. **Параллельная загрузка полных текстов** обсуждений для каждого найденного отзыва (при необходимости).

Количество одновременно выполняемых задач ограничивается заданным числом потоков.

## Основные сущности

В зависимости от источника используются следующие сущности:

| Сущность | Описание | Поля |
|----------|----------|------|
| **Publication** | Статья с сайта Habr | идентификатор, название, автор, дата публикации, время чтения, количество просмотров, рубрики, текст превью, ссылка на изображение, имя файла изображения |
| **Theater** | Информация о театре | название, список спектаклей |
| **Performance** | Отдельная постановка | название, дата и время проведения, продолжительность, возрастное ограничение, ссылка на изображение афиши |
| **Review** | Отзыв с сайта BookMix | название книги, список авторов, текст отзыва, имя автора отзыва, количество звёзд |

## Функциональное назначение

Программный комплекс предназначен для **автоматизированного извлечения информации из веб-источников**.

Информация на сайтах обычно представлена в виде HTML-страниц, ориентированных на просмотр человеком. Для анализа, систематизации и повторного использования такие данные удобнее хранить в структурированном виде.

## Формат результатов

Все парсеры сохраняют результат в `output/` в формате JSON.

## Выходные данные

При работе парсеров автоматически создаются следующие папки:

```
ParseLib/
├── images/    # афиши театров и изображения статей Habr
├── output/    # итоговые JSON-файлы
└── logs/      # логи работы парсеров
```
